## Safe relocation / isolation rules

For any **future** plan-gated cycle (scoped or otherwise):

1. **Atomic nested git** — move intact trees that contain `.git`; never strip history / `filter-repo` / force-push.
2. **Named parent units only for scoped FS** — prefer whole `_backups` and/or `_quarantine` parents; do not cherry-pick empty `.git` shells.
3. **Opaque `.env*`** — path presence only; never read/quote/log contents; list unread paths in intent-preview.
4. **Remotes path-only** — inventory names + schemes; **no** `git remote set-url` / origin rewrite unless a later gated step explicitly says so (default: document only).
5. **No linked-worktree surprise** — re-run `git worktree list` immediately before any approved move on each **nested clone path** (the directory that owns that `.git`). Do **not** probe parent wrapper dirs (e.g. `_backups` / `_quarantine`) when those parents are tracked content of an outer repo — parent-dir `worktree list` resolves to the **outer** repo and is not a nested-clone signal. If unexpected >1 worktree appears on an in-scope nested clone, fail-closed.
6. **Windows lock recovery** — prefer a single move; on PermissionDenied/split → reunify + `robocopy /E /MOVE`; remove **only empty** leftover `.git` shells; re-attest; log deviation.
7. **Whole XL `WorkSpace` → ordinary Multi-experiment archive** — **OUT OF SCOPE** until dedicated clearance; never claim “solved” that way under ordinary Continuity.
8. **Consent** — Continuity / Choose ≠ plan-gate approval; any `fs_mutation` needs a separate gate + intent-preview.
9. **Row honesty** — after docs-only, scoped isolation, or remote-config clearance, Multi-experiment stays **in progress** with **Remaining: `WorkSpace` only** while the XL tree remains; **never** mark Complete or jump Primary next / Special git (live multi-remote cleared Cycle 15 — still not Complete).
