# Notes

Personal Markdown notes for this organisation repo. Put free-form `.md` files here — not catalogue inventory, not corpus reorganisation storage, and not FAW session artifacts (`sessions/*/notes.md`).

## Add a note

Create a new `.md` file in this folder.

Recommended filename pattern: `yyyy.mm.dd-topic.md` (example: `2026.09.09-meeting-ideas.md`).
